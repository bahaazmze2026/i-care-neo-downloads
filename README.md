# i-CARE SYSTEM — NEO downloads

This repository provides a public **experimental QA preview** of the Windows x64 installer and its checksum. No approved stable release is currently available.

Use an isolated test environment with synthetic data only. The preview is **not approved for production or patient care**. Windows acceptance remains pending; supported OS/runtime requirements are not yet verified. The installer is unsigned: do not bypass Windows security warnings.

Get the installer and SHA-256 file from [Releases](https://github.com/bahaazmze2026/i-care-neo-downloads/releases). The application source and its Git history are not stored in this repository. Download availability does not establish free application licensing or source redistribution rights.
